# Challenge Format

Each challenge only contains a problem statement.

Example:

## Challenge 01 — Find Student

### Problem

Create an array with **5 student names**.

Create a function that takes two parameters:

- `allStudents`
- `studentName`

Iterate through the array and find the student whose name matches `studentName`.

Return the student's name if found.

Otherwise, return `"Student not found"`.

---

# Rules

- Read the problem carefully.
- Solve it without searching for the answer.
- Avoid using built-in methods unless the challenge allows it.
- Focus on writing clean and readable code.
- Refactor your solution after it works.
- Analyze the time and space complexity when possible.
